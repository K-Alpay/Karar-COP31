# Eko-Bürokrat: COP31 Yolunda 🌿🏛️

> **COP31 Hackathonu için Reigns Tarzı İklim ve Bürokrasi Simülasyonu**

---

## 🎮 Nasıl Oynanır & Nasıl Çalıştırılır?

### 1. Yöntem (En Kolay)
Tarayıcını (Chrome, Firefox, Brave vb.) aç ve adres çubuğuna şunu yaz:
```
http://localhost:8080
```
*(Sunucu arka planda hazır bekliyor!)*

### 2. Yöntem (İnternetsiz / Sunucusuz)
Doğrudan klasördeki `index.html` dosyasına çift tıklayıp herhangi bir tarayıcıda açabilirsin.

---

## 🕹️ Kontroller
* **Fare / Dokunmatik:** Kartı tutup **Sola** (Reddet) veya **Sağa** (Onayla) fırlat.
* **Klavye:** 
  * `Sol Ok` veya `A`: Reddet
  * `Sağ Ok` veya `D`: Onayla
* **Butonlar:** Kartın altındaki kırmızı/yeşil butonlara tıkla.

---

## 📊 4 Ana Gösterge (Dengeleme)
1. 💰 **Bütçe:** 0'a düşerse şehir iflas eder.
2. 🌿 **Eko-Skor:** 0'a düşerse ekolojik felaket olur ve COP31'den elenirsin.
3. 🎓 **Gençlik:** 0'a düşerse gençler şehri terk eder, beyin göçü başlar.
4. 👔 **Başkan:** 0'a düşerse başkan seni kovar!
